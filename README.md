# ecoguard
# EcoGuard (에코가드)
> **현대차 Pleos Connect 기반 배터리 수명 솔루션 & 에코 드라이빙 리워드 서비스**

---

## 1. 앱 이름 및 한 줄 소개
* **앱 이름:** EcoGuard (에코가드)
* **한 줄 소개:** 실시간 지형 고저차 및 CAN 텔레메트리를 분석하여 전기차 배터리 열화(SOH)를 방어하고, 수명 연장 가치를 현대카드 M포인트로 즉시 보상하는 차세대 IVI 배터리 케어 솔루션

---

## 2. 주요 기능
* **지형 기반 배터리 케어 경로:** 내리막 관성주행(Coasting), 급커브 회생제동 충격 분산 가이드
* **실시간 배터리 스트레스 지수(BSI):** 양극재 격자 수축 및 리튬 석출 방어 상태 실시간 시각화
* **P단 체결 감성 보상 및 가치 환산:** 수명 연장(+2.4일) 및 중고차 감가 보존액(+4,200원 상당) 즉시 산출
* **현대카드 M포인트 & 현대카페이 연계:** 원터치 +420 M포인트 즉시 적립 및 E-pit 충전 결제 연동
* **시간대별 IVI 환경:** 아침 출근길 / 낮 일상 / 야간 퇴근길 맞춤형 테마 및 보이스 안내

---

## 3. 실행 방법

### 방법 A. 안드로이드 APK 설치 (권장)
1. 저장소 내 `apk/` 폴더에서 `ecoGuard_release.apk` 파일을 다운로드합니다.
2. 안드로이드 스마트폰/태블릿 기기로 파일을 전송한 뒤 설치합니다.
3. 앱을 실행하면 Pleos Connect 풀스크린 IVI 모드로 구동됩니다.

### 방법 B. 웹 브라우저 실시간 인터랙티브 데모 (설치 불필요)
* **Live Demo URL:** [https://so2124467-maker.github.io/ecoguard/](https://so2124467-maker.github.io/ecoguard/)
* 모바일 및 PC 브라우저(Chrome, Edge, Whale 권장)에서 접속 즉시 시뮬레이션을 동일하게 체험할 수 있습니다.

---

## 4. 테스트 환경 및 필요한 설정
* **권장 테스트 기기:** Android 8.0 이상 기기 또는 웹 브라우저 (Chrome, Edge 최적화)
* **필요 설정:**
  * 안드로이드 설치 시: '출처를 알 수 없는 앱 설치' 허용
  * 음성 피드백(TTS) 청취를 위한 기기 미디어 볼륨 활성화
  * 인터넷 연결 (데이터 또는 Wi-Fi)
